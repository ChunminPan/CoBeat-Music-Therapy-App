WeChat Mini Program - Rhythm Training (Stage1 + Stage2 DDA)

How to run:
1) Open WeChat DevTools -> New Project -> choose this folder as project directory.
2) AppID can be empty/test.
3) Click Compile.

Notes:
- Stage1: fixed BPM 60-80, 60s round, pass >=70% unlock Stage2
- Stage2: DDA updates every 10 taps using acc10 and meanErr10, adjusting bpmCur and range.
- Export button copies JSON logs to clipboard for analysis.
